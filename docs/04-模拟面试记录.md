# 04 · 模拟面试记录（3 位候选人）

> 说明：以下候选人均为**模拟人物**，用于验证多 Agent 协同流程、题库与评分表的可执行性，不对应真实个人。
> 统一流程：初面 15 min → 技术面 45 min → HR 面 30 min，共 9 轮。
> 评分：1–5 分（锚点见 `03-评分表.md`）；每位候选人由三名面试官独立打分，评估官只汇总与校准。
> 记录格式：轮次 / 面试官 / 题号 / 主维度 / 回答摘要与追问 / 分值 / 评分依据。
