岗位职责

六个方向，覆盖「开发—集成—交付—质量」

  • 01知识库后端服务：文档接入、解析编排、切片入库、检索与会话
  • 02Agent 与模型对接：工具调用网关、任务队列、超时重试与可观测
  • 03政企业务系统：进销存、生产管理、CRM、园区管理接口与权限
  • 04数据与接口设计：表结构、索引、REST 契约、接口文档
  • 05私有化交付：离线部署、数据迁移、升级回滚、现场排障
  • 06质量与协作：单测、代码评审、组件沉淀、排障手册

必备能力 · MUST HAVE

  • 一门主力语言（Java / Go / Python / Node.js），能写清晰分层代码
  • 数据库基本功：SQL、索引、事务、隔离级别、慢查询
  • HTTP / REST 契约：状态码、鉴权、分页、幂等、超时
  • Git、Linux、Docker：能起本地依赖、看日志、排查环境
  • 测试与排障：会写单测，能按日志 / 指标定位问题

加分能力 · NICE TO HAVE

  • RAG / 向量检索：Milvus、pgvector、FAISS、ES 向量检索
  • 大模型应用：API 调用、工具调用、流式输出、限流与降级
  • 消息队列：Kafka / RabbitMQ / RocketMQ，懂削峰与幂等
  • 私有化部署与安全：离线镜像、权限分级、审计、加密
  • 低代码 / 可观测：表单流程引擎、Prometheus、ELK

胜任力模型 · 四层十二项

每一层都能落到题目与评分锚点，不做「感觉不错」的判断

专业硬技能语言与基础 · 数据与存储 · 接口与集成 · 检索与 AI 应用
